Datenlöschung für Meta- und Instagram-Daten

So können Sie die Löschung personenbezogener Daten beantragen, die über die Anwendung „SocialMedia Hailey DM“ verarbeitet werden.

So stellen Sie eine Löschanfrage

  1. Senden Sie eine E-Mail mit dem Betreff „Datenlöschung Instagram“ an adrianmurmann@gmx.de.
  2. Nennen Sie Ihren Instagram-Benutzernamen oder eine andere eindeutige Instagram-Kontokennung. Senden Sie niemals Ihr Passwort oder einen Zugangscode.
  3. Beschreiben Sie kurz, ob sich die Anfrage auf Nachrichten, Kommentare, Profildaten oder sämtliche zuordenbaren Instagram-Daten bezieht.
  4. Zur Vermeidung unberechtigter Löschungen kann eine angemessene Bestätigung verlangt werden, dass Sie das betroffene Konto kontrollieren.

Bearbeitung

Die Anfrage wird manuell geprüft. Nach erfolgreicher Zuordnung wird ermittelt, welche aktiven Datensätze dem angegebenen Instagram-Konto zugeordnet werden können und welche Löschung, Anonymisierung oder Einschränkung rechtlich und technisch durchgeführt werden kann. Sie erhalten eine Rückmeldung zu den umgesetzten Maßnahmen oder zu bestehenden Einschränkungen. Die Bearbeitung erfolgt ohne unangemessene Verzögerung und grundsätzlich innerhalb eines Monats.

Eine Löschung kann insoweit eingeschränkt sein, wie gesetzliche Aufbewahrungspflichten oder die Geltendmachung, Ausübung oder Verteidigung von Rechtsansprüchen eine weitere Speicherung erfordern. In diesem Fall werden die Daten nur noch für den betreffenden Zweck verarbeitet.
